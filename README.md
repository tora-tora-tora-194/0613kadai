# 🏡 家族の家事シェアボード

家族間でリアルタイムに家事の状況を共有し、楽しく家事を分担・協力するためのWebアプリケーションです。

## 🚀 サービス概要
「誰がどの家事をやったか」「今どんな家事が残っているか」を家族みんなで見える化します。
付箋のような親しみやすいデザインで、PCからもスマートフォンからも直感的に操作・確認ができる設計にしています。

## 👤 ターゲットユーザー
- 家族間で家事の分担をスムーズに行いたい方
- リアルタイムに家事の完了状況を共有したい家族（Tさん、Rさん、Kさんなど）
- スマホでサクッと家事のチェックを行いたい方

## ✨ 主な機能
1. **リアルタイムな家事共有機能**
   - 誰かが家事を追加したり、完了状態にしたりすると、他の家族の画面にもリアルタイムに反映されます。
2. **直感的なUI/UX**
   - ひと目で状況がわかる付箋風のデザインを採用。
   - スマホ（Safari等のモバイルブラウザ）でも文字が美しく収まるよう、CSSで細かなピクセル単位の微調整（レスポンシブ・折り返し対策）を行っています。

## 🛠️ 使用技術（開発環境）
- **フロントエンド:** HTML / CSS（Flexboxを用いたレイアウト、レスポンシブ対応） / JavaScript
- **バックエンド/インフラ:** Firebase (Cloud Firestore / Firebase Hosting)

## 💡 こだわった点・苦労したポイント
- **ブラウザ間の表示崩れ対策（Safari対策）:**
  iPhoneのSafariで開いた際、画面幅によって特定の文字（「ボード」の『ド』など）が不自然に改行されてしまうバグに直面しました。CSSの `white-space: nowrap;` や `letter-spacing`（文字ツメ）、`font-size` のミリ単位の調整、さらに強力なブラウザキャッシュを突破する検証を重ねることで、どの端末で見ても美しく1行に収まるデザインを実現しました。
